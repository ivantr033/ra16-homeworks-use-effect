# Домашнее задание к блоку «Hooks & Context API» — Задача «useEffect»

Веб-приложение на React 19 и TypeScript 5 для просмотра списка пользователей и загрузки подробной информации о выбранном профиле с использованием хука `useEffect`.

* **Users List App:** [Открыть приложение](https://ivantr033.github.io/ra16-homeworks-use-effect/)

## ⚙️ Реализованные требования и технические характеристики

* **Разделение эффектов загрузки:** В корневом компоненте `App` хук `useEffect` загружает общий список пользователей один раз при монтировании. В компоненте `Details` отдельный `useEffect` отслеживает изменение идентификатора `info.id` и подгружает детальный профиль.
* **Отмена устаревших запросов (`AbortController`):** При быстром переключении между пользователями или размонтировании компонента предыдущий сетевой запрос корректно прерывается, предотвращая гонку состояний (*race conditions*).
* **Защита от повторной загрузки:** В компоненте `List` клик по уже активному элементу игнорируется, исключая лишние сетевые запросы.
* **Обработка состояний:** Реализованы индикаторы загрузки и перехват сетевых ошибок с понятным выводом в интерфейс.

## 🛠️ Технологический стек

* **Фронтенд:** React 19 (`useState`, `useEffect`, `AbortController`)
* **Язык:** TypeScript 5 (строгая типизация моделей данных без использования `any`)
* **Сборщик:** Vite 8
* **CI/CD:** GitHub Actions (автоматический деплой на ветку `gh-pages`)

## 🔧 Инструкция по установке и запуску

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/ivantr033/ra16-homeworks-use-effect
   cd ra16-homeworks-use-effect
   ```

2. Установите зависимости:

   ```bash
   npm install --legacy-peer-deps
   ```

3. Запустите проект в режиме разработки:

   ```bash
   npm run dev
   ```

   Приложение откроется локально по адресу `http://localhost:5173`.

4. Для создания production-сборки выполните:

   ```bash
   npm run build
   ```
